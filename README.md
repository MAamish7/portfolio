# Mohammad Aamish — Portfolio

A cinematic, dark-themed personal portfolio for a B.E. Mechanical Engineering student at
SJEC Mangaluru. Built with Next.js (App Router), TypeScript, Tailwind CSS, GSAP + ScrollTrigger,
Lenis, Three.js / React Three Fiber, and Framer Motion.

**Live sections:** hero (WebGL) · about · skills · work (stacked case studies) · timeline ·
education · certificates · contact.

---

## Stack

| Layer          | Choice                                            |
| -------------- | ------------------------------------------------- |
| Framework      | Next.js 14 (App Router), React 18, TypeScript     |
| Styling        | Tailwind CSS + shadcn-style primitives (Radix)    |
| Scroll         | Lenis, synced to GSAP's ticker                    |
| Animation      | GSAP + ScrollTrigger, SplitType, Framer Motion    |
| 3D             | Three.js, React Three Fiber, Drei                 |
| Icons          | lucide-react                                      |

## Getting started

```bash
npm install
npm run dev          # http://localhost:3000
```

Other scripts:

```bash
npm run build        # production build
npm run start        # serve the production build
npm run lint         # ESLint (next/core-web-vitals)
npm run typecheck    # tsc --noEmit
npm run export       # static export to ./out (see "GitHub Pages" below)
```

Node 18.17+ is required (Node 22 is what this was built and tested on).

│   │                       # certificates, contact
│   ├── three/              # WebGL scene, particle galaxy, floating geometry, noise shader
│   └── ui/                 # button, card, badge, dialog, input + animation primitives

**Editing content:** everything the site displays lives in `src/constants/`. Change a
project, a certificate or a phone number there and it propagates everywhere — no component
edits needed.

## Portrait assets

`public/images/` is generated from the studio "character sheet" contact sheets:

```bash
node scripts/prepare-portraits.mjs sheet-a.jpg sheet-b.jpg
```

The script splits each sheet into its panels, writes a square headshot, and produces an
alpha-cut full-body figure. Background removal is a border-seeded flood fill with two
thresholds — a small step tolerance so the fill can crawl along the backdrop's gradient, and
a bounded total drift so it can never ramp its way onto the subject — followed by a 2px
erosion and a feather to kill the halo.

Re-run it only when the source photos change; the outputs are committed.

## Notes on behaviour

- **Contact form** — the site is fully static, so submitting composes a pre-filled `mailto:`
  in the visitor's mail client rather than posting to a server. To switch to a real endpoint
  (Formspree, Resend, a route handler), replace the `window.location.href` assignment in
  `src/components/sections/Contact.tsx`.
- **Sound** — off by default. The toggle synthesises short blips with the Web Audio API, so
  no audio files ship with the site.
- **Easter egg** — enter the Konami code (`↑↑↓↓←→←→ B A`) anywhere outside a form field.
- **Reduced motion** — `prefers-reduced-motion: reduce` skips the WebGL canvas entirely
  (a static gradient stands in), disables Lenis, and resolves every GSAP reveal to its end state.
- **WebGL failures** — the scene is wrapped in an error boundary and uses a locally generated
  environment map, so no CDN fetch or driver problem can blank the page.

## Performance

- WebGL is `dynamic()`-imported with `ssr: false`; every below-the-fold section is code-split.
- Device pixel ratio is capped and adaptive; `PerformanceMonitor` halves the particle count
  and DPR if the frame rate drops.
- Animations are transform/opacity only, and Lenis shares GSAP's single RAF loop rather than
  running a second one.
- Images are pre-sized and served unoptimised so the build stays export-safe.

## Accessibility

- Skip link, semantic landmarks, one `h1`, labelled controls, and visible focus rings.
- The typewriter and animated counters expose their full value to screen readers.
- Skill meters are exposed as `role="meter"` with min/max/now.
- The custom cursor only replaces the system cursor on fine-pointer devices.

## Deployment

### Vercel (recommended)

1. Push this branch to GitHub.
2. In Vercel, **Add New → Project** and import `MAamish7/portfolio`.
3. Vercel auto-detects Next.js — keep the defaults:
   - Framework preset: **Next.js**
   - Build command: `next build`
   - Output directory: `.next`
   - Install command: `npm install`
4. No environment variables are required.
5. Deploy. Then set `SITE.url` in `src/constants/site.ts` to the final domain so the canonical
   URL, sitemap and Open Graph tags point at the right place.

Or from the CLI:

```bash
npx vercel        # preview deploy
npx vercel --prod # production deploy
```

### GitHub Pages (static export)

The app also builds to a fully static bundle:

```bash
npm run export    # NEXT_OUTPUT=export next build  →  ./out
```

The repository currently has two Pages workflows (`.github/workflows/static.yml` and
`jekyll-gh-pages.yml`) that publish the legacy single-file site kept at `index.html` in the
repo root. To publish this app on Pages instead, point a workflow at `npm ci && npm run export`
and upload `./out` as the Pages artifact. Note that Pages serves from a subpath unless you use
a `<user>.github.io` repo or a custom domain — set `basePath`/`assetPrefix` in
`next.config.mjs` if so.
